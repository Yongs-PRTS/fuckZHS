# 2026-10-31 自动答题维护与发布说明

本轮修复针对源码。测试不使用真实账号、不调用付费模型、不提交真实作业，因此不能据此保证平台当前接口、全部课程页面和模型正确率。

## 修复内容

- AI 课程：取消模型异常后的随机答案；读取所有试卷分组，检查题目 ID、题型、选项和答案数量后才保存。所有题目保存成功才能提交。
- AI 课程：无效缓存重新生成答案；平台不公开答案时不写入空缓存；空评分记录不会再导致异常。失败时停止心跳。
- AI 课程：带 `/v1`、其他版本或完整路径的模型地址统一处理；外部模型可复用桌面配置和环境变量。
- AI 课程：每个知识点默认最多尝试 3 次，全对立即退出；达到上限报出未完成，避免无限重试和假成功。
- AI 课程：修复长参考资料超过 27,900 token 时使用浮点数切片导致的异常；兼容答案代码块的 CRLF 换行，拒绝空回复与文本模式下的图片题。
- 作业模型：拒绝未知标签、重复答案、单选多答、字符串冒充数组、漏空以及当前文本模式无法读取的图片题。支持第 11 个及以后的标签和字符串 ID。
- 普通作业：重做后重新核对试卷，变化时重新生成答案；剩余次数扣除已重做次数与本次初始重置；已选答案不一致时保留页面供人工处理。
- 浏览器：点击真实控件并读回结果，不通过直接设置 `checked` 伪造作答成功；支持非数字选项 ID；作业列表去重。
- 配置：命令行与桌面共用默认配置；清空本机 Key 后，环境变量 Key 不会意外发往旧配置的其他服务商地址。
- 发布：添加无密钥配置样例、离线测试工作流、白名单源码打包和校验清单，排除配置、登录态、抓包、缓存、日志和构建输出。
- CodeQL 更新为 v4 并同时覆盖 main/master，依据 [GitHub 官方迁移说明](https://github.blog/changelog/2025-10-28-upcoming-deprecation-of-codeql-action-v3/)。

## 使用范围

| 入口 | 题型与行为 |
| --- | --- |
| 桌面作业 / `homework_browser.py` | 单选、多选、判断；验证码人工处理；默认填完人工提交 |
| `homework.py --run` | 接口模式支持选择、判断、文本填空；完整作答后自动提交；平台要求验证码时可能无法使用 |
| `main.py -ai COURSE_ID CLASS_ID` | AI 知识图谱课程；选择、判断；完整作答后自动提交，按上限重试 |

图片、复杂公式和非标准页面仍需人工确认。浏览器选中状态与页面提交成功提示是当前校验依据；本轮没有验证真实平台的保存、评分与提交结果。

## 验证与发布

```powershell
python -m unittest discover -s tools -p "test_*.py" -v
python tools/audit_checks.py
python tools/prepare_release.py
```

测试覆盖异常模型输出、全试卷、多选残留、重做换题、重做次数、失败停止、成功提交模拟、页面 DOM 回读、界面状态、浏览器启动与桌面恢复。
新增 GitHub Actions 会运行同样的离线检查；工作流本身尚未在远程仓库执行。

本机验证：32 项单元测试、28 项审计回归检查通过。源码包在隔离目录解压后验证核心模块导入与离线测试。
真实 Edge 的空白页夹具验证选项点击、隐藏重复项、取消点击后的状态，以及两个浏览器实例互不干扰。
exe 使用隔离假配置验证 TLS 资源、本机健康接口、密钥掩码、前端资源一致性、正常退出与后台进程错误上报。
这些检查均不代表真实平台作业提交或答题准确率测试。

`releases/ZHS-source.zip` 是可上传的源码包，`.manifest.json` 保存逐文件 SHA-256。
它由白名单生成，不是把整个项目目录压缩。`config.example.json` 为空白配置；请勿把本机 `config.json` 改名后发布。

在源码包解压目录新建 Git 仓库，保留 `.github`、`.gitignore`、原作者与 MIT LICENSE，再推送到自己的 GitHub 仓库。
本轮未初始化仓库、创建远程仓库或推送内容。

Windows 发布构建可使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1 -OutputDir .\releases
python tools/smoke_packaged.py --exe .\releases\ZHS-Desktop.exe
```

只将 `ZHS-Desktop.exe` 作为 Release 附件。已有 `dist` 中的旧 exe 与运行数据不属于本轮源码包。
