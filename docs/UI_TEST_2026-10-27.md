## 这次补查出的打包问题

已有错误记录显示，扫码和同步在创建 HTTPS 上下文时触发 `FileNotFoundError`。
当前构建所用的 Python 运行时在 `ssl` 模块初始化时需要相邻的 `codex-rejected-cas.pem`，此前该资源没有进入 exe。

已修改 `build_windows.ps1`：检测并带入这项运行时资源，同时显式收集 certifi 的证书文件。保留原有的证书校验行为。

新增 `zhs_app.py --self-check <输出JSON>`，检查 TLS 上下文、客户端 TLS 上下文、证书校验和 CA 文件；加 `--https-probe` 可用无账号 Cookie 的请求测试公共登录域名。
`tools/smoke_packaged.py` 现在必测 TLS 初始化，增加 `--network` 可测试真实 HTTPS。

修复后的打包和联网结果在完成后记录到 `PACKAGED_SMOKE_2026-10-27.json`。
