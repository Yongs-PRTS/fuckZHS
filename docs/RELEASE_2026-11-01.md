# v2.6.4 · 2026-11-01

## 这个版本提供什么

面向 Windows 的智慧树 / 知到学习助手：扫码登录和课程同步、批量课程学习、视频弹题处理，以及普通作业、章节测试、单元测试和见面课测验的模型辅助填写。AI 知识图谱课程提供独立命令行流程。

普通作业默认填写后人工提交，验证码人工完成。桌面里可以配置模型、测试连接、查看进度和日志、停止任务和切换账号。

## 已知范围

离线回归、真实 Edge 本地夹具和打包冒烟测试不等于真实平台验收。本轮没有使用真实账号提交作业，模型正确率、平台接口变化、课程差异仍需使用者核对。浏览器模式不支持填空与图片题；遇到不支持的题型请手动作答。

开发者注意：平台接口签名按上游协议使用 MD5，CodeQL 会提示弱哈希。它不用于存储用户密码；为维持接口兼容性，本版保留该协议实现与告警，不将扫描流程成功等同于没有安全告警。

## 下载与使用

Windows 用户下载 `ZHS-Desktop.exe`，放到独立可写目录后启动。源码用户按 README 安装依赖运行 `python zhs_app.py`。

升级时保留本机 `config.json`、登录态和其他个人文件，只替换 exe。请勿把带个人数据的整个程序文件夹上传或转发。
